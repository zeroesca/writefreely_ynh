## Enable Email Functionality

To enable email sending using yunohost's built-in mail server, you'll need to add the lines below to `__INSTALL_DIR__/config.ini`, save it and then restart the Writefreely daemon:

```
[email]
domain                = __DOMAIN__
smtp_host             = 127.0.0.1
smtp_port             = 25
smtp_username         = __APP__
smtp_password         = __MAIL_PWD__
smtp_enable_start_tls = true
```

Alternatively, Writefreely also supports the Mailgun API; more details at https://writefreely.org/docs/v0.16.0/admin/config
