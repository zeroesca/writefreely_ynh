## Enable Email Functionality

Since version 0.15.0, Writefreely has supported using email to send password resets and to enable readers to subscribe to your posts.

To enable sending email using yunohost's built-in mail server, you'll need to add the lines below to `__INSTALL_DIR__/config.ini`, save it and then restart the Writefreely daemon:
```
[email]
domain                = __DOMAIN__
smtp_host             = 127.0.0.1
smtp_port             = 25
smtp_username         = __APP__
smtp_password         = __MAIL_PWD__
smtp_enable_start_tls = true
```

Alternatively, to enable sending email via the Mailgun API, add these lines instead, replacing the $values with the relevant info:
```
[email]
mailgun_private       = $your-mailgun-api-sending-key
mailgun_europe        = $true-or-false_depending-on-your-mailgun-account
```

Once email is enabled, you can turn it on for each blog by going to `Customize` and scrolling down to the `Updates` section. You can also add a reply-to address to accept private replies via email.
