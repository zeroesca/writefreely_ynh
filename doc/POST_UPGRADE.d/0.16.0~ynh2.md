To enable email sending, edit __INSTALL_DIR__/config.ini to add these lines, then save and restart the Writefreely daemon:

`[email]`
`domain                = __DOMAIN__`
`smtp_host             = 127.0.0.1`
`smtp_port             = 25`
`smtp_username         = __APP__`
`smtp_password         = __MAIL_PWD__`
`smtp_enable_start_tls = true`
